# WakeGemini
A simple app for Honor phones with an AI button (running Chinese firmware) to quickly wake up Gemini instead of YOYO.


## Permission Granted

Use this command to give permission for the app

`adb shell pm grant com.example.wakegemini android.permission.WRITE_SECURE_SETTINGS`


## Disable YOYO series APPs

package:com.honor.yoyocards
package:com.hihonor.magicvoice
package:com.hihonor.collectcenter
